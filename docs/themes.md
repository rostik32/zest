# Themes

The popup's colors come from a theme. zest ships with 74 themes converted from popular VS Code
themes, can import any VS Code theme, and can use the theme your VS Code or Cursor is using.

Pick one in **Settings → Appearance**: search the list, and the preview below it changes as you
click. There you can also:

- **Use a light theme when macOS is in Light mode**: choose a dark and a light theme; the popup
  switches with the system appearance.
- **In VS Code and Cursor, use the editor's theme** (on by default): in the editor's terminal the
  popup takes the colors of the editor's current color theme, read from its settings and extension
  folders. Elsewhere your chosen theme is used.
- Choose the **font** (any installed monospaced font; Menlo by default), its size, the number of
  rows and the width.

## A theme file

A theme is a YAML file with up to 11 colors, written as `#RRGGBB` (or `#RRGGBBAA`). Colors that
are left out come from One Dark Pro Darker (dark themes) or a plain light theme.

```yaml
# ~/.config/zest/themes/my-theme.yaml
name: My Theme
appearance: dark          # dark or light
colors:
  background: "#1E2227"   # the popup
  border: "#181A1F"       # its outline and the line above the footer
  selection: "#2C313A"    # the selected row
  text: "#ABB2BF"         # suggestion names
  selectedText: "#D7DAE0" # the name in the selected row
  match: "#ECEBEB"        # the letters you typed (also bold)
  description: "#818791"  # descriptions on the right
  command: "#8CC265"      # icons of commands
  subcommand: "#C162DE"   # icons of subcommands, and the footer text
  option: "#4AA5F0"       # icons of options
  argument: "#D18F52"     # icons of arguments (branches, scripts, …)
```

The file name (without `.yaml`) is the theme's id. Put your themes in `~/.config/zest/themes`
(**Open Themes Folder** in Settings); a file there replaces a built-in theme with the same name.
Changes show up the next time you open Settings or change a setting.

## Importing a VS Code theme

In Settings, click **Import VS Code Theme…** and choose a theme's `.json` file or an extension
folder, or use the command line:

```bash
zest theme import ~/Downloads/my-theme.json
zest theme import ~/.vscode/extensions/some.theme-1.0.0     # every theme the extension has
zest theme list                                              # what zest can use
zest theme editor cursor                                     # the theme Cursor uses, converted
```

The colors come from VS Code's own suggest widget (`editorSuggestWidget.*`), falling back to the
editor's colors and VS Code's defaults. Descriptions use the text color at 70% opacity, as VS Code
draws them. The icon colors come from the terminal colors (`terminal.ansiGreen`, `ansiMagenta`,
`ansiBlue`, `ansiYellow`); a color that is too close to the background is replaced by its bright
variant.

## The bundled themes

`themes/` is generated by `scripts/update-themes.sh` (`make themes`). It downloads each extension
listed in the script from [Open VSX](https://open-vsx.org), converts its themes, drops variants
that only differ in font style, and copies each extension's license into `themes/LICENSES`.
[`themes/SOURCES.md`](../themes/SOURCES.md) lists where every theme comes from.

To add a theme to zest, add its extension to the list in the script, check that its license
allows redistribution (MIT, ISC, BSD or Apache 2.0), run `make themes` and open a pull request.
`make test` checks that every bundled theme is complete and readable.
